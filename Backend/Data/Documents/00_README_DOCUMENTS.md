# Bộ tài liệu RAG khởi đầu

Các file trong thư mục này có thể được đưa vào quy trình embedding để kiểm thử RAG.

Các tài liệu mô tả chức năng trợ lý AI, cách sử dụng, quyền truy cập dữ liệu và nguyên tắc Smart Timetable. Chúng không thay thế quy chế đào tạo chính thức của trường.

Trước khi demo các câu hỏi về điều kiện dự thi, chuyên cần, học lại hoặc cách tính điểm, cần bổ sung tài liệu chính thức tương ứng và ghi rõ nguồn, ngày hiệu lực.

Không đưa password, API key, JWT, connection string, file `.env`, dữ liệu toàn bộ sinh viên hoặc dữ liệu production nhạy cảm vào thư mục này.
